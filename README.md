# OnPoint
Real-time credit card recommendation system that helps users maximize cashback, points, and financial benefits at every purchase. Built as a Chrome extension with a Node.js backend and MongoDB data platform

# Features
- Real-time card recommendations while shopping
- Personalized card discovery for new users
- Insights dashboard showing rewards earned & savings over time
- Chrome extension 

# Architecture
- Frontend      Chrome Extension (Javascript)
