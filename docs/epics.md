# ----------------------- OnPoint Epics ----------------------

This document outlines the major feature sets requires to build OnPoint 

# Epic 1 User Onboarding:
- Build a secure access system for users to create accounts, log in, and manage their data.

#   Key Features
    - Email + password authentication
    - Store user profile preference
    - Ability to add/remove credit cards

# Epic 2 Card Discovery & Benefits:
- Build a secure access system for users to create accounts, log in, and manage their data.

#   Key Features
    - Email + password authentication
    - Store user profile preference
    - Ability to add/remove credit cards

# Epic 3 Recommendation Engine (Core MVP):
- Provide real-time card recommendation for a given spending category

#   Key Features
    - Best card logic at first
    - Return recommended card + estimated reward

# Epic 4 Savings & Insight Dashboard
- Help users visualize their earnings and improvements over time.

#   Key Features
    - Track savings earned per recommendation
    - Display total cashback / points value

# Epic 5 Merchant & Insights Expansion (Future)
- Increase accuracy by auto-detecting purchase categories using website and merchant metadata.
#   Key Features
    - Detect merchant within browser context
    - Map merchants to dynamic categories
    - Enhance recommender precision automatically

## Development Priority
