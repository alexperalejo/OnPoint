# OnPoint Chrome Extension 

This folder contains the frontend code for OnPoint credit card recommendation system.
The Chrome extension allows users to receive real-time recommendations while browsing and shopping online

## MVP Goals
- Display a popup UI when the extension icon is clocked
- Allow user to select a spending category (ex: Grocery, Dining, Travel, etc..)
- Request recommended credit card from backend API
- Show card name and potential reward back to user

## Key Files (Planned)
- `manifest.json` - Extension configuration
- `popup.html` - UI window
- `contentScript` - Detect website 
- `background.js` - Event handling + permissions
